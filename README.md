# World Dominion

Przeglądarkowa współczesna gra grand strategy. Zawiera prawdziwą mapę polityczną świata z granicami państw, wybór kraju, zarządzanie prowincjami, gospodarkę, budowę, armie, dyplomację, zapis gry i płynący w czasie rzeczywistym zegar.

## Uruchomienie

Otwórz `index.html` w przeglądarce lub uruchom lokalny serwer:

```bash
python3 -m http.server 8000
```

Następnie wejdź na <http://localhost:8000>. Połączenie internetowe jest potrzebne do pobrania kafelków OpenStreetMap oraz danych granic świata Natural Earth udostępnianych przez Highcharts Map Collection.

## Rozgrywka

- kliknij dowolne państwo na mapie, aby sprawdzić jego dane i rozpocząć działania dyplomatyczne,
- wybierz prowincję, wznoś budynki i obserwuj kolejkę budowy,
- rekrutuj i trenuj armie, zarządzając pieniędzmi oraz rezerwami,
- kontroluj prędkość upływu czasu lub zatrzymaj grę,
- przełączaj mapę polityczną, gospodarczą, relacji i siły militarnej,
- zapisz postęp lokalnie przyciskiem **ZAPISZ**.
