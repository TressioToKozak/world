# World Dominion

Interaktywny prototyp współczesnej globalnej gry strategicznej inspirowanej rozgrywką grand strategy. Gracz wybiera państwo, zarządza prowincjami, rozwija infrastrukturę i tworzy armie.

## Uruchomienie

Otwórz `index.html` w przeglądarce lub uruchom lokalny serwer:

```bash
python3 -m http.server 8000
```
